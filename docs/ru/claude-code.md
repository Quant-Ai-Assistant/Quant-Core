# Claude Code

[English version](../en/claude-code.md)

Бот может работать с кодом через Claude Code CLI, а не через свои shell и файловые инструменты. Сам бот продолжает отвечать на своей модели, а работа с кодом идёт в Claude Code со всеми его инструментами, субагентами, навыками и `CLAUDE.md` проекта.

## Вход

Откройте **Настройки → Claude Code** и нажмите **Войти через Claude** (Claude Pro или Max) или вставьте API-ключ Anthropic. Этот аккаунт использует только Claude Code. Модели, на которых боты общаются в чате, от него не меняются.

Если здесь не войти, CLI использует тот вход, который уже есть на компьютере бота, например `claude`, в который вы сами вошли на этом Mac.

## Включение для бота

Откройте настройки бота и включите **Claude Code**. Затем выберите:

- **Модель**: Fable, Opus, Sonnet или Haiku, либо модель CLI по умолчанию.
- **Усилие**: Low, Medium, High, Extra high или Max, либо значение CLI по умолчанию.

Они действуют только для запусков Claude Code этого бота. Бот может общаться на маленькой модели, а код писать на Opus с высоким усилием.

Чтобы отправить через Claude Code один запрос, наберите `/` в поле сообщения и выберите **Claude Code**.

## Что видно

Пока Claude Code работает, в чате видна карточка **Claude Code** с текущим шагом (читает файл, правит файл, запускает тесты, ищет в интернете) и последними шагами. Когда он заканчивает, карточка сворачивается до числа шагов и времени работы; нажмите на неё, чтобы увидеть все шаги.

В звонке плашка под именем бота показывает тот же шаг, например **Claude Code · Правит файл**.

## Компьютер

Claude Code запускается на компьютере бота, в папке бота, если бот не указал папку проекта. Если на компьютере нет CLI, бот получает подсказку поставить его командой `curl -fsSL https://claude.ai/install.sh | bash`.

Claude Code работает без запроса разрешения на каждый шаг, потому что бот и так может выполнить на своём компьютере любую команду. Для работы, которую нужно изолировать, используйте отдельный компьютер.
