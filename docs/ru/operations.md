# Эксплуатация

[English version](../en/operations.md)

Команды из этого руководства выполняются в папке установки — там, где лежит `.env`. Большинство использует такую приставку:

```sh
dc() { docker compose --env-file .env -f docker-compose.images.yml "$@"; }
```

## Состояние и логи

```sh
dc ps            # все сервисы и их состояние
dc logs -f api   # следить за логом одного сервиса
```

## Остановка и запуск

```sh
dc down          # остановить и удалить контейнеры, данные остаются
dc up -d         # запустить снова
```

## Смена пароля шлюза

Удалите строки шлюза из `.env` и запустите установщик снова: он сохранит всё остальное и спросит только настройки шлюза.

```sh
sed -i.bak '/^QUANT_BASIC_HASH=/d;/^QUANT_GATE_TOKEN=/d' .env
bash install-images.sh
```

После этого каждому устройству нужен новый пароль. Удаление `QUANT_GATE_TOKEN` также выводит браузеры и приложения, которые проходили шлюз раньше.

## Смена порта

Поменяйте в `.env` значение `QUANT_PORT` и порт в `WEB_ORIGIN`, `BETTER_AUTH_URL` и `API_URL`, затем выполните `dc up -d`. Обновите адрес в приложениях.

## Резервные копии

Всё хранится в двух Docker-томах, `quant_pgdata` (база) и `quant_appdata` (файлы), плюс `.env`. Дамп базы:

```sh
dc exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' > quant-$(date +%F).sql
```

Восстанавливайте его в пустую базу через `psql` в том же контейнере. Храните `.env` вместе с дампом: без `ENCRYPTION_KEY` сохранённые ключи провайдеров не прочитать.

## Удаление Quant

```sh
dc down -v       # удаляет и базу, и файлы
```

Затем удалите папку установки.

## Безопасность

- **У сервиса обновления есть доступ к Docker-сокету**, а это равно правам root на хосте. Он слушает только закрытую сеть, до которой достаёт сервис `api`.
- **Обычный HTTP** передаёт пароль шлюза незашифрованным. Используйте домен с HTTPS, VPN или сеть, которой доверяете.
- **Регистрация открыта** по умолчанию: аккаунт может создать любой, кто прошёл шлюз. Создав свой, укажите в `.env` `SIGNUPS_ENABLED=false` и выполните `dc up -d`.
