# Подключение приложений

[English version](../en/connect.md)

Любое устройство попадает на сервер Quant через шлюз, с логином и паролем, заданными при установке. Приложения запоминают их и отправляют с каждым запросом, поэтому вводить их нужно один раз.

## Браузер

Откройте адрес сервера, например `http://192.168.1.10:8080`. Браузер спросит логин и пароль шлюза, затем покажет страницу входа Quant.

## Android

1. Откройте на телефоне последний [релиз](https://github.com/Quant-Ai-Assistant/Quant-Core/releases/latest) и скачайте `quant.apk`.
2. Откройте файл. В первый раз Android попросит разрешить установку из браузера или файлового менеджера — разрешите и установите.
3. Запустите Quant и нажмите **Use a custom server**.
4. Введите адрес сервера, а под ним логин и пароль шлюза, затем нажмите **Save**.
5. Войдите в свой аккаунт Quant.

При неверном пароле появится «The server did not accept that username and password». Адреса `http://` работают только для локальной сети; публичному серверу нужен `https://`.

## macOS

1. Скачайте `.dmg` из последнего релиза: `arm64` для Apple Silicon, `x64` для Intel.
2. Откройте его и перетащите **Quant** в **Applications**.
3. Запустите Quant. macOS сообщит, что не может проверить разработчика: приложение не подписано Apple Developer ID. Нажмите **Done**.
4. Откройте **System Settings → Privacy & Security**, нажмите **Open Anyway** рядом с сообщением о Quant и подтвердите.

Терминал делает то же, что шаг 4:

```sh
xattr -dr com.apple.quarantine /Applications/Quant.app
```

5. В окне настройки выберите **Existing instance**, введите адрес сервера, логин и пароль шлюза и нажмите **Continue**.

Пароль хранится в связке ключей macOS. Чтобы позже сменить сервер, выберите **Change Quant Server…** в меню приложения.

## Windows

Запустите установщик `.exe` из последнего релиза. SmartScreen предупредит о неизвестном издателе: нажмите **More info**, затем **Run anyway**. Дальше выберите **Existing instance**, как на macOS.

## Linux

Скачайте `.AppImage`, сделайте его исполняемым и запустите:

```sh
chmod +x Quant-*.AppImage
./Quant-*.AppImage
```

## Сервер на компьютере

Десктопное приложение может само запустить сервер Quant на этом же компьютере через Docker:

1. В окне настройки выберите **Этот компьютер**.
2. Чтобы заходить с телефона или другого компьютера, заполните **Логин для других устройств** и **Пароль**. Оставьте их пустыми, если сервер нужен только на этом компьютере.
3. Нажмите **Продолжить**. Приложение скачает и запустит Quant, затем откроет его.

Если логин задан, окно настройки показывает адрес для туннеля, например `http://localhost:8080`: это шлюз, который спрашивает у других устройств этот логин и пароль. Направьте на него туннель (Cloudflare Tunnel, ngrok, Tailscale Funnel) и введите на телефоне публичный `https://`-адрес туннеля вместе с тем же логином и паролем. Устройства в той же сети могут использовать и `http://<адрес этого компьютера>:8080`.

Чтобы сменить логин или пароль либо закрыть доступ, откройте **Change Quant Server…**, измените поля в разделе **Этот компьютер** и нажмите **Продолжить**. Пустой пароль оставляет текущий. Новый пароль выводит другие устройства из шлюза.
