# Обновления

[English version](../en/updates.md)

Каждый пуш в `main` этого репозитория создаёт релиз `v0.1.<сборка>`: образы сервера, Android-APK и десктопные приложения с одной и той же версией. Каждая часть обновляется сама из последнего релиза.

## Сервер

Под аккаунтом владельца сервера откройте **Settings → Updates** и нажмите кнопку обновления.

Сервис `updater` после этого:

1. читает самый новый тег релиза этого репозитория;
2. записывает в `.env` соответствующий тег образа (`sha-<коммит>`), сохраняя предыдущий;
3. скачивает новые образы и пересоздаёт `api`, `worker`, `web` и `supervisor`.

Миграции базы выполняются при старте нового `api`. Если новые контейнеры не запустились, сервис возвращает предыдущий тег образа.

То же самое можно сделать из оболочки в папке установки:

```sh
docker compose --env-file .env -f docker-compose.images.yml pull
docker compose --env-file .env -f docker-compose.images.yml up -d
```

## Android

Откройте **Account** и нажмите **Check for updates**. Если в последнем релизе сборка новее, кнопка превращается в **Install update v0.1.N**: приложение скачивает `quant.apk` и открывает системный установщик Android. В первый раз Android попросит разрешить установку из Quant.

Номер сборки в теге (`N` в `v0.1.N`) — это код версии приложения. Каждый релиз подписан одним и тем же ключом, поэтому он ставится поверх текущего приложения и сохраняет ваши данные.

## Десктоп

Десктопное приложение проверяет последний релиз при запуске и каждый час и показывает состояние в разделе обновлений приложения.

- **Windows и Linux:** обновление скачивается в фоне и ставится при перезапуске.
- **macOS:** приложение не подписано Apple Developer ID, поэтому macOS не даёт заменить его на месте. В этом случае приложение открывает последний релиз в браузере: скачайте новый `.dmg` и снова перетащите Quant в Applications.

## Версии

| Часть | Откуда берётся версия |
| --- | --- |
| Релиз | `v0.1.<номер запуска>` workflow `release` |
| Образы сервера | Теги `v0.1.N`, `sha-<коммит>`, `edge` и `latest` |
| Android | `versionName` `0.1.N`, `versionCode` `N` |
| Десктоп | Версия приложения `0.1.N` |
