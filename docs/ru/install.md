# Установка сервера Quant

[English version](../en/install.md)

Сервер Quant — это набор Docker-контейнеров. Один установщик скачивает Compose-файл, задаёт несколько вопросов и запускает всё. На сервере ничего не собирается: образы берутся из релизов этого репозитория.

## Что нужно

- Linux или macOS с Docker Engine и плагином Docker Compose. На macOS — Docker Desktop или OrbStack.
- `curl` и `openssl`.
- Около 10 ГБ свободного места под образы и ещё место под ваши данные.
- Свободный TCP-порт для Quant. Установщик проверит его сам.

## Запуск установщика

```sh
mkdir -p quant && cd quant
curl -fsSLO https://github.com/Quant-Ai-Assistant/Quant-Core/releases/latest/download/install-images.sh
bash install-images.sh
```

Установщик задаёт четыре вопроса:

| Вопрос | Что ответить |
| --- | --- |
| Domain for HTTPS | Для домашней сети оставьте пустым. Домен указывайте, только если он уже указывает на этот сервер, а порты 80 и 443 свободны. |
| Port for Quant on this server | Любой свободный порт, по умолчанию `8080`. Занятый порт установщик не примет и спросит снова. |
| Address phones and other computers will use | Адрес сервера в вашей сети, определяется автоматически, например `192.168.1.10`. |
| Username and password for the gate | Логин и пароль Basic Auth, которые нужны каждому устройству. Если оставить пароль пустым, установщик сгенерирует его и покажет один раз. |

В конце установщик выводит адрес, например `http://192.168.1.10:8080`, и логин шлюза.

## Что запускается

| Сервис | Роль |
| --- | --- |
| `gate` | Caddy с Basic Auth. Единственный сервис, который слушает сеть, на выбранном порту. |
| `web` | Веб-интерфейс. Доступен только через шлюз (и на `127.0.0.1:5173` на самом сервере). |
| `api`, `worker` | Приложение и его фоновые задачи. |
| `supervisor`, `computer` | Компьютеры ботов: по одному Docker-контейнеру на компьютер. |
| `postgres` | База данных. На хосте не публикуется. |
| `updater` | Применяет обновления из **Settings → Updates**. |

## Файлы в папке установки

| Файл | Содержимое |
| --- | --- |
| `.env` | Все настройки и секреты; установщик создаёт его с правами `600`. |
| `docker-compose.images.yml` | Сервисы из таблицы выше. |
| `Caddyfile.gate` | Настройки шлюза. |

Храните `.env` в секрете и делайте его резервную копию: в нём пароль базы, ключ шифрования сохранённых ключей и хеш пароля шлюза.

## Установка без вопросов

Задайте ответы переменными, и установщик ничего не спросит:

```sh
QUANT_PORT=8080 QUANT_PUBLIC_HOST=192.168.1.10 \
QUANT_BASIC_USER=quant QUANT_BASIC_PASSWORD='choose-a-password' \
bash install-images.sh
```

Для HTTPS на домене добавьте `QUANT_DOMAIN=quant.example.com`.

## HTTPS

С доменом шлюз получает сертификат Let's Encrypt и отдаёт `https://` на порту 443. Без домена Quant работает по обычному HTTP в вашей сети. В этом случае:

- пароль шлюза идёт по сети незашифрованным, поэтому используйте его только в сети, которой доверяете;
- браузеры дают доступ к микрофону только по HTTPS, поэтому голос работает в Android-приложении, но не в браузере на другом устройстве.

## Первые шаги

1. Откройте выведенный адрес и введите логин и пароль шлюза.
2. Создайте аккаунт. Первый аккаунт становится владельцем сервера.
3. Подключите провайдера модели, когда приложение попросит, и создайте первого бота.

Затем подключите телефон и компьютер: см. [Подключение приложений](connect.md).
